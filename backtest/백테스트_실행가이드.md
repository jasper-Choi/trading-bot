```

├── coin_backtest.py      ← 코인 RSI 평균회귀 전략
```

## 4단계 — 주식 백테스트 실행

```powershell

```

pykrx 설치 시 실제 KRX 데이터로 실행됩니다.
pykrx 없이 실행 시 샘플 데이터로 시뮬레이션합니다.

---

## 5단계 — 결과 해석

### 통과 기준

| 지표 | 코인 기준 | 주식 기준 |
|------|----------|----------|
| 샤프 비율 | ≥ 1.2 | ≥ 1.0 |
| 승률 | ≥ 48% | ≥ 45% |
| 손익비 | ≥ 1.5 | ≥ 1.5 |
| 최대 드로우다운 | ≥ -12% | ≥ -10% |
| 거래 횟수 | ≥ 30회 | ≥ 20회 |

### 결과별 대응

**✅ 통과** → 모의투자 단계로 진입
**❌ 미달 — 승률 낮음** → `rsi_entry`를 25로 낮춰서 재시도
**❌ 미달 — 드로우다운 큼** → `stop_loss_pct`를 0.01로 줄여서 재시도
**❌ 미달 — 거래수 부족** → `backtest_days`를 늘리거나 코인 종류 추가

## 6단계 — 파라미터 조정 방법

`coin_backtest.py` 상단 CONFIG 딕셔너리만 수정하면 됩니다:

```python
CONFIG = {
    "rsi_entry": 30,        # 낮출수록 진입 기준 엄격 (25~35 사이 시도)
    "stop_loss_pct": 0.015, # 줄일수록 드로우다운 감소 (0.01~0.02)
    "take_profit_pct": 0.025, # 익절 목표 (0.02~0.04)
    "volume_mult": 1.5,     # 높일수록 진입 기준 엄격
    ...
}
```

⚠️ 주의: 파라미터를 너무 많이 조정하면 과최적화됩니다.
수정은 1개씩, 이유 있게, 결과를 기록하면서 진행하세요.

## 워크포워드 테스트 (과최적화 방지)

백테스트 통과 후 반드시 이 추가 검증을 해야 합니다:

```
전체 기간 180일을 두 구간으로 나눔
- 구간 A (앞 120일): 파라미터 최적화
- 구간 B (뒤 60일): 검증 (파라미터 고정, 결과 확인)

구간 B 결과가 구간 A의 70% 이상이면 → 과최적화 아님
구간 B 결과가 구간 A의 50% 미만이면 → 과최적화 의심, 재검토
```

`backtest_days`를 120으로 설정 후 실행 → 결과 기록
`backtest_days`를 60으로 설정 + 시작일을 60일 전으로 맞춰 실행 → 비교
